# ICEBREAKER
Un repositorio vivo de icebreakers, dinámicas y experimentos para romper el hielo en workshops, formaciones y sesiones de trabajo.
El contenido del index cambia con el tiempo: a veces encontrarás juegos, otras prototipos, otras ideas en bruto.
Si has llegado buscando algo concreto y ves otra cosa… es normal. Este repo evoluciona según el contexto.
